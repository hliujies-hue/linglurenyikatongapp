# 最新需求基线 · 2026-10-13

- APP 首次实际 SDK 在线一机一码激活，再使用景区子账号和密码登录；平台地址可设置为 HTTPS 域名。平台自动登记设备，APP 不填景区、不手工绑定设备、不填写后台 SDK 配置。
- 景区主账号管理景区，子账号归属于主账号；同一子账号可在不同手机登录。核验规则属于子账号：普通或单点，设备不再固定绑定业务账号。
- 首次实际核验的账号、设备、规则及景区保存事件快照。单点与普通之间的当天入口约束由平台事务判定；次数、间隔、权益同样由平台判定。
- 后台人工补录不绑定设备，计入景区次数和报表，但不占用某个子账号/设备的首次入口。后台主账号、子账号均可由获授权的平台管理员删除，保留业务历史和补传能力。
- 手机接收照片，用提供的真实 SDK 提取特征、执行检测/质量/活体/检索；平台不运行人脸算法。撤权优先删脸。30 万真实人员容量与速度必须真机验收。
- 一次连续人脸呈现仅产生一次尝试；人脸离开至少 1.5 秒再出现可产生新尝试。每次尝试先写本地记录，再请求平台；没有有效持久化回执不通行。
- 断网/超时不离线放行。失败记录持续补传；确认回执失败继续重试；补传不能重放成功提示或重复放行。
- 记录序号连续且重启不丢失。每七天清理一次已满七天且已确认的本地事件，未确认事件保留。清理不重置序号。
- 换号/调拨先暂停核验，完成原账号人员任务、事件补传和回执确认，再释放会话。更新不清空记录、授权或签名。
- APP 仅显示简单日期筛选的景区共享人数，不展示人员详细轨迹或抓拍。管理后台平台账号可查询全部景区并筛选、导出统计/明细，景区账号受所属范围限制。
- 景区人数按同人、同景区、同日去重；期间合计为每日人次之和。另有期间去重人数，字段要明确，不能相加终端或账号分组代替景区总计。
- 提示文字/语音由平台配置；无效人员默认未识别到有效用户，次数规则拒绝默认异常003。
- 测试环境限定清理旧硬件运行数据、无效配置与脏绑定，不留该清理的数据备份；保留用户、年卡、订单、历史入园和当前 Android 会话。
- 正式签名、本地构建安装，GitHub 同步维护代码；每轮更新必须提供平台 Bash 和 APP Windows PowerShell 的完整命令。
