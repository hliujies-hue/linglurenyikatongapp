# 验收检查

## 已执行

- 从上传 AAR 读取并核对 FaceAuth、FaceDetect、FaceLive、FaceFeature、FaceSearch 及图像类型的真实 Java 方法签名。
- Java 核心规则测试：10 项通过。范围包括未确认数据永久保留、七天年龄界限、时钟回退、过期/错事件/后台响应禁止显示通过、次数超限文案。

- 8 个 Java 文件通过 JDK 语法解析，Android XML 解析通过；不等于 Android 构建。
- FaceEngine 使用实际 AAR 编译核对通过，仅提供 Context/Bitmap 类型占位供签名校验，未替代 Android 平台 API 编译。

## 本地首次验证

1. Preflight 找到 Android Studio JBR、Android 35、匹配 SDK AAR 与模型。
2. Build-Release 执行 core 检查、Android release 编译、lint 和 APK 签名验证。
3. 安装保留数据，不自动卸载。检查没有白屏；未激活只有激活入口。
4. 输入授权码，真实联网激活；错误码和断网错误明确，界面不显示厂商品牌。
5. 模型加载成功后出现登录页和明确标为不通行的相机算法检查入口。
6. 相机权限拒绝、前后镜头、旋转、切后台/回前台、屏幕照片/视频翻拍与真人分别验证。
