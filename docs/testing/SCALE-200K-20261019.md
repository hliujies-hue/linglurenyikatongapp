## 现场验收与操作
1. 先平台再APP，平台迁移增加手机信息字段；旧端省略字段不清空已知信息。手机信息需通过现有通信凭据验证才更新；已删除手机保留历史信息，不开放匿名上报或自动恢复。
2. 后台设备列表查看品牌/型号、Android系统；摘要仍为定位依据，型号不能单独证明身份/授权。
3. APP维护配置安装包记录支持分页、归档并清理。当前下载URL/摘要与最新两个已发布包受保护；待发布包先取消。归档先提交状态再删文件，失败可重试，保留版本/审计；无自动清理任务。
4. 服务器缓存清理默认预览，显式 --apply 才执行。新增 --rebuildable-caches（Go超过2GiB；Node超过512MiB且只删两天前文件）、--stale-build-caches（两天前、原源码逐文件Git哈希核对、无恢复材料的测试构建，只清忽略的依赖缓存）。不删除业务数据、恢复备份、原源码、pnpm工具目录。
5. 网页上传→确认发布→APP内下载→系统覆盖安装仍需真实设备联调；未声称此前置灰或全部更新流程现场验收通过。
